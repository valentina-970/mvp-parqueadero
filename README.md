# MVP Parqueadero

Sistema MVP de gestión de parqueadero: ingreso por placa, cobro por día operativo, pago en efectivo y control de salida. Proyecto final de Ingeniería de Software II, Universidad Autónoma de Manizales.

## Tecnologías

Java 21, Spring Boot 4.1, PostgreSQL, React con Vite, Docker Compose.

## Estructura

- `backend/`: API en Spring Boot
- `frontend/`: aplicación React
- `docs/`: documentación y registro Scrum

## Cómo correr el proyecto

Pendiente. Se completará cuando exista el Docker Compose.

## Flujo de trabajo

- Ramas: `main` (versiones), `develop` (integración) y `feature/HU-xx-descripcion`.
- Commits con Conventional Commits, por ejemplo `feat(HU-02): calcular cobro`.
- Todo cambio entra por pull request aprobado por otro integrante.
- Tablero: GitHub Projects del repositorio.
