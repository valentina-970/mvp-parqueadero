# Contexto para asistentes de IA

Este es el proyecto MVP Parqueadero (Ingeniería de Software II, UAM).

Antes de escribir código, lee `docs/contexto/README.md`: ahí están el orden de lectura, las reglas del proyecto y el estado actual del código. Para programar una historia, lee además su sección en `docs/contexto/03-product-backlog.md`.

Reglas que no se rompen:

- Trabaja una historia a la vez, en una rama `feature/HU-xx-descripcion` creada desde `develop`.
- No hagas commits directos a `main` ni a `develop`.
- No subas secretos ni el archivo `.env`.
- No edites una migración de Flyway ya aplicada: crea una nueva.
- No generes diagramas (la docente lo prohíbe).
